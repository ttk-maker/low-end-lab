# v0.6.2 面向学习者的保守教学策略

2026-11-08。

目标从“让用户校正模型后才能练习”调整为“先提供证据支持的简单练习，复杂识别细节按需展开”。强化的是建议的可执行性、可重复性与证据要求，不是把不确定结果说得更肯定。

## 音频识别与学习建议分层

BTC 与小节结构解码是确定性推理，没有文本生成温度。此次没有改变模型权重、分类分数或上一版和弦解码参数，不人为锐化概率。新增学习建议层：

- 完整和弦证据集中：优先给出根音节奏练习，候选和弦可展开查看。
- 根音集中但性质有歧义，例如 Am 与 Am7：只推荐 A 根音，明确暂不使用三音/七音，不要求初学者先分辨七和弦。
- 根音分歧、未知类别占比高、或一小节有不同根音变化：提供闷音节奏练习，不猜具体音高，也不把多个根音压成一个。
- 整小节为低能量 N：建议数拍与留白，并说明这是低能量候选，不保证原曲完全静音。

根音建议需要所有具体和弦分数总和至少 0.80、首选根音总分至少 0.75、领先其他根音至少 0.30；若有不同根音的已解码变化或静音片段，不能推荐整小节单一根音。完整和弦说明还要求单一分段、分数至少 0.65、领先至少 0.25。阈值是保守筛选规则，不是“75%/80% 准确率”，尚未做真实歌曲校准。

无需点击“人工确认”即可阅读并尝试这些练习；候选、原始区间与未采纳标签折叠到“查看识别候选与依据”。人工确认仍用于正式校正和 Qwen 歌曲依据，不伪造确认状态。已有人工保存结果仍优先显示，不被学习建议覆盖。音高建议基于机器证据，可能出错，不是原曲贝斯转录。

## Qwen

显式设置 `temperature=0.2`。旧版本没有发送该参数，因此不能准确声称从某个已知数值降低到 0.2。低温减少生成变化，不保证绝对确定或消除幻觉。

提示词要求面向无法自行判断识别错误的学习者，给出一个优先方案，先节奏/根音，再解释必要构成音；不把听辨纠错作为开始练习的前提。信息不足时给不依赖未知音高的练习，不编造原曲调性、和弦和贝斯音。缓存键包含教学策略版本与温度，避免继续复用旧策略答案。此次仍不发送音频，自动歌曲上下文仍要求保存且有效的确认依据。

已使用实际配置执行一次简短文字请求，服务接受 temperature=0.2 并返回中文答案；接口报告总用量 147 tokens（输入 65、输出 82，输出含推理用量）。这证明参数兼容与连接可用，不代表完成教学质量评测或确定性统计实验。

## 验证

新增学习建议断言：同根音不同性质、不同根音冲突、未知质量占比高、强证据和弦、多根音变化、静音。既有和弦结构测试通过；18 项 Python 测试通过，其中检查实际请求参数及教学提示词。浏览器验证无需人工确认即可显示练习、详细候选折叠展开、原始模式切换、回听及 390px 布局。测试没有保存或修改原曲项目。
