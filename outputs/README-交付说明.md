## 打开原有静态练习页

在当前文件夹双击 `index.html`，建议使用 Edge 或 Chrome。若从压缩包获得文件，先完整解压，保持 `index.html`、`prototype.js`、`fretboard-model.js` 在同一目录。无需安装依赖或输入 API Key。浏览器首次播放需要点击按钮。

推荐体验：

1. 在工作台选择“编我的贝斯线”，当前是原创 Night Pocket 的 Am7 → Fmaj7。
2. 点击“试试连接音”，再点击“播放”；先听 E1 怎样进入 F1。
3. 选第一个小节的 4& 格，将它设为休止，听没有连接音的版本；用撤销恢复。
4. 选中任意格，点击指板写入音符；注意第二小节的指板和弦已切换为 Fmaj7。
5. 关闭示范贝斯，拿琴跟伴奏演奏两轮，再点击“弹完了，记录我的感受”。
6. 到指板实验室比较标准调弦与 Drop D，或把 A 改作 Fmaj7 的三音来看。

本地草稿与自评保存在当前浏览器；更换浏览器/文件路径可能属于不同存储位置。可在学习记录导出 JSON。切换练习范围会替换当前编辑区示例，切换前先导出希望保留的版本。
