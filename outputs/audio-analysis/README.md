## 新电脑或移动后的完整包

1. 安装 Python 3.10，以及一个带 pip 的默认 Python（pip 需支持 `--python`，建议 23+）。
2. 在此目录运行 `powershell -ExecutionPolicy Bypass -File install.ps1`。
3. 运行上级目录的启动脚本。依赖只装入 `.venv`，不改动系统 Python 包。

当前电脑使用项目 `work/audio-env` 的独立 Python 3.10 环境；复制到其他电脑时该路径一般不存在，启动脚本会使用这里的 `.venv`。Windows CPU 路线已经实际运行，其他平台需要另行适配启动脚本。无需 API Key。

## 已实现

- 导入 MP3/WAV/FLAC/OGG，4 秒至 10 分钟、最大 30 MB。
- 本机解码并生成实际波形。
- Beat This! small0 神经模型检测 beats/downbeats，使用实际拍间距而非整曲强制等间隔。
- 段落使用 32 个对数频率带、两侧各 2 秒特征差、0.25 秒步长和峰值过滤，输出声学变化候选。
- 播放原音频、显示当前候选小节/拍位、可选提示音、0.5/0.75/1 倍回放、指定时间区间循环。
- 波形点击定位，方向键移动，片段放大/全曲切换。
- 半速/倍速拍点、全体前后 10 ms 偏移、手工固定 BPM/首拍网格、手工每小节拍数与强拍重设。
- 段落名称、边界移动、当前位置拆段、相邻合并、逐段确认。
- 撤销、恢复机器结果、保存人工校正、明确人工确认、JSON 导出。
- 队列任务与可取消状态、重复音频复用结果、异常提示、损坏/过短音频拒绝。
- 音频与校正在本地保存，不上传外部服务。

## 示例结果

`erkanmanavoglu-in-space-183782.mp3` 解码有效时长 **23.69306 秒**（MP3 容器信息约 23.719 秒，差异来自解码帧/填充；网页播放器的 duration 与有效解码长度一致）。采样率 44100 Hz，双声道。

- 中位拍间距推算 BPM：130.43；约 65.22 或 260.86 是可比较的半速/倍速解释，不是额外已确认的节奏。
- 37 个拍点，10 个强拍候选；强拍间的多数拍数为 4。它不是已确认的 4/4 拍号分析。
- 拍点从 0.02 秒到 16.66 秒；之后未检测到拍点，未自动延长。
- 段落候选：0–7.50、7.50–15.25、15.25–23.69306 秒。
- 单次 CPU 分析实测约 10–12 秒，含模型加载；不是对所有机器/音频的性能承诺。

段落边界来自声学变化，不是 all-in-one 的语义结构分类。此版没有自动标成主歌/副歌，也没有调用大语言模型。边界强度只是相对变化分数，不是准确率或校准概率。

## 文件与数据

- `engine.py`：音频解码、Beat This!、段落基线、波形与结果。
- `server.py`：本机服务、任务状态、保存校正、版本冲突处理、音频 Range 播放。
- `analysis.js / analysis.css`：嵌入现有原型的真实分析页。
- `playback-sync.js`：提示音提前调度、原曲输出路由与队列取消。
- “画面提前量”只补偿本浏览器显示，默认 0，正值提前；不改写拍点、不移动提示音，重置可恢复。
- `models/small0.ckpt`：官方 Beat This! 权重；下载 URL 与 SHA-256 见下。
- `data/<音频哈希前20位>/audio.*`：原始音频副本。
- `data/<id>/analysis.json`：机器结果 + 独立的 `annotation`。人工校正不会改写原始 beats/downbeats/segments。

`revision` 防止多页面互相覆盖；旧版本引擎重新分析前会备份旧结果。重复上传同一音频且引擎版本一致时使用缓存；节拍失败的结果允许重新分析。手动修改不自动等同于已确认，只有用户的确认动作才改变确认状态。

取消发生在计算步骤边界；正在进行的单次模型推理不会强制杀进程，完成该步后不提交新结果。关闭整个服务时正在运行的任务可能中断，已写入的结果仍在。

## 验证与实际边界

已运行真实 MP3、独立 120 BPM 合成测试、静音、损坏与过短音频；已验证拍点有序且位于音频内、段落连续覆盖、校正字段合法。120 BPM 合成测试的检测音头中位误差为 0 秒（该简单测试不代表真实歌曲准确率）。

浏览器验证包括原曲时钟、循环回绕、尾段未检出状态、另一文件上传后真实推理、半速/倍速与撤销、段落拆分/移动/重命名、保存刷新恢复、原始结果不被覆盖、版本冲突、Range 请求，以及 1440/834/390 布局。原有 21 品模型 91 项断言通过。

没有独立教师标注的真值，不能报告此 MP3 的拍点或段落准确率。提示音改为每 25 ms 检查、提前最多 150 ms 排入 Web Audio 时钟，原曲与提示音共用输出通路；暂停、跳转、变速、编辑和循环会清理或重建队列。仍受媒体时钟与输出延迟影响，不能用于演奏毫秒级评分；循环使用 HTML 音频时钟，尚不承诺采样级无缝循环。播放变速使用浏览器保音高功能，音质受浏览器影响。
