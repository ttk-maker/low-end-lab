# v0.6.1 小节和弦稳定性优化

2026-11-08。

## 原因与实现

截图中的小节卡原先只是把原始 BTC 区间裁切到小节边界，没有结合小节上下文重新解码。第一小节有约 0.09 秒 X 和约 0.02 秒下一小节的 Am7，因此即使主要证据是 Am，仍显示三个片段。当前项目原始节奏与和弦均未保存人工 annotation，本次不会擅自将节奏设为已确认。

新增 `bar-stability-v1` 结构解码器：

- 在每个小节内，对半拍单元的完整 BTC 分数按时间重叠加权；使用动态规划比较持续和弦与换和弦分段，切换需支付复杂度代价。
- 默认偏好持续至少 0.75 拍的和弦；半拍变化需要较高且明显领先的证据。没有硬编码“每小节最多两个”，强证据支持时允许更多变化。
- 短暂不确定可由同一段的整体证据支持；连续超过一拍的低分/近似平分区间成为不可跨越的未知屏障，不会仅为减少 X 强行填和弦。
- 小节边界重新评估，减少相邻小节的几十毫秒预测串入。强证据的半拍提前换和弦保留，不无条件吸附到小节线。
- 持续低能量 N 保留原始边界；拍点覆盖之外保留原始候选，不外推小节。完整保留七和弦类别，不把 Am7 一律简化成 Am。

参数：换和弦代价 0.10（以整小节时长归一化），分段平均分数至少 0.32、领先分数至少 0.08；短于 0.75 拍的半拍段要求分数至少 0.75、领先至少 0.30。分数并非校准置信度。参数在 8 项合成对照前确定，未根据测试成绩继续调参；这些是复用回归样本，不是新的独立保留集。

## 使用与保护

没有人工和弦校正的项目默认显示“小节稳定候选”预览。切换“原始 / 当前编辑区间”可以对照原始碎片。预览期间点击小节或和弦回听，不把预览冒充为已保存校正；当前播放标签使用同一预览候选。下方原始区间编辑器明确标注来源。

先核对节奏并锁定保存，再点击“按已锁定节奏生成稳定候选” → “采用按拍候选” → 回听确认 → 保存。采用可撤销；已有人工校正默认显示当前保存内容，不自动用新解码覆盖。仍保留上一版节奏版本检查、过期依据拒绝与 Qwen 保护。

卡片标出上下文处理的 X 时长与未采纳候选。后者可能包含真实快速和弦，不能把“更少”当作“必然更准”。若实际节奏网格逐渐偏离，小节和弦也会错位；此算法不改变或掩盖拍点时间，需要先校正节奏。

## 当前原曲候选

前三小节从 Am/X/Am7、Am7/X、X/D/X 收敛为 Am、Am7、D。第四小节为 Am，短 E7 未采纳并明确提示。第六小节 Am/Am7/A7 证据冲突，仍输出 X；第八小节保留 D→Am。以上只是结构化机器候选，不是新获得的人工真值，也不能证明 E7 一定是误检。

## 评测

复用 8 个合成样本，给定 120 BPM / 四拍网格，隔离评估和弦结构化步骤。没有重新训练 BTC 或更改节奏模型。

| 指标 | 原始 BTC v2 | 小节稳定候选 |
|---|---:|---:|
| 按时长标签正确率（含静音） | 80.60% | 88.16% |
| 音乐区间正确率 | 76.58% | 85.86% |
| 输出区间总数 | 49 | 27 |
| 快速换和弦样本正确率 | 86.94% | 75.00% |
| 非网格边界样本正确率 | 99.66% | 98.57% |

收益主要来自低音量和短暂不确定区间。快速变化与非网格边界存在退步，所以保留原始模式、未采纳候选及可撤销流程。没有将这组结果外推为真实歌曲准确率。

逻辑测试覆盖短 X、边界串入、每小节两/四个和弦、强提前半拍、持续未知、整体模糊、七和弦保留、精确静音、网格外保留和输入不变。浏览器验证预览/原始切换、回听、锁定后采用、撤销、保存重载、保留人工校正与 390px 布局；原有 18 项 Python 测试通过。
