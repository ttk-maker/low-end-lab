# Qwen 连接故障排查与修复

日期：2026-11-08。

## 已确认原因

本机配置地址的 `.cn-beijing.maas.aliyuncs.com` 后缀重复了一次。DNS 可以解析，但 Python 在 HTTPS 握手时返回 `SSLCertVerificationError`，校验码 62（域名与证书不匹配）。使用系统代理及直接连接均能复现。原实现将此错误与超时合并提示，导致网页只显示“无法连接百炼或请求超时”。

## 修复与验证

- 去掉重复域名后缀前，先验证修正地址能够通过 HTTPS 校验；未携带凭据的请求正常返回 HTTP 401。
- 已修正本机私有配置中的地址，API Key 未修改；原配置备份仍仅保存在工作区私有目录中，不包含在交付包内。
- 配置校验拒绝重复域名后缀；网络错误区分证书域名不匹配、其他证书错误、DNS 失败、超时与其他连接失败。没有关闭 TLS 证书校验，没有自动重试。
- 通过网页使用的后端问答接口发送一个简短文字问题，百炼返回认证失败，未得到模型回答。另以携带凭据的模型列表请求复核，得到 HTTP 401 / `invalid_api_key`。
- Qwen 离线测试共 9 项通过，包含重复地址拒绝和错误分类／脱敏；修复后的后端已重启部署。

## 当前状态及用户下一步

网络地址故障已修复；真实问答仍受认证失败阻塞。当前测试不能证明模型可用、回答质量或实际 Token 用量。

请在百炼控制台核对或新建与服务地址地域、业务空间匹配的 API Key，再通过本机配置工具保存完整 Key。不要使用阿里云 AccessKey ID、AccessKey Secret、工作空间 ID 或模型名称替代 API Key。具体原因可能是 Key 类型、复制内容、有效期或地域／空间不匹配，仅凭 401 无法进一步判定。

配置工具重新输入地址时，应复制官方完整 base_url，不要再次拼接后缀。修改文件配置后，在工作台点击“检查本机配置”，再提问。无需将 Key 发给助手。
