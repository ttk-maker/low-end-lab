## 已实现的闭环

选择音频 → 本地上传与解码 → 神经节拍检测 → 声学段落候选 → 播放和拍点同步 → 循环回听 → 调整拍点/边界 → 保存/确认/导出。

用户的校正独立存储，原始机器结果保留。静音不生成虚构 BPM；损坏文件返回明确错误；拍点失败可保留波形与段落分析。服务只监听本机，不调用云端 API。

## 本轮技术选择

拍点采用已核实的 Beat This! small0，可在本机 CPU 上运行。结构先采用可解释的频谱变化基线，使这台 Windows 电脑能完成真实数据闭环；没有把它冒称为 all-in-one 的功能段落分类。音乐大模型不参与本阶段的时间戳测量。

下一阶段需要实现和弦候选、人工确认与真实指板联动。此 MP3 的调性、和弦和原曲贝斯音符本轮没有分析，不从歌曲标题、网页信息或示例进行推断。
